alter       :-- will perform operation on table 		architecture

>>>add column      :-- will add a new column to 			existing table

>>>at last :
--------------
>>>alter table table_name add column column_name datatype;

>>>at middle :-
-------------------
>>>alter table table_name add column column_name datatype after exsting_column_name;

>>>at first :--
---------------------
>>>alter table table_name add column column_name datatype first; 



>>>rename column  :-- will used to change the 				column_name
---------------------------------------------
>>>alter table table_name rename column old_column_name to new_column_name;



>>>drop column   :-- will used to remove the columns 			from a table
-----------------------------------------------
>>>alter table table_name drop column column_name;

>>>change datatype  :--  will change datatype
-----------------------------------------------
>>>alter table table_name modify column old_column_name new_datatype;
