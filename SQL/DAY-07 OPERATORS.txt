OPERATOR :-- will perform an operation between operands or values or operand to values




arithmetic    :-- will perform the mathematical operations
			(+,-,*,/,%,**)
comparison    :-- will compare the values or operands or values to 			operand
			(=,>,<,>=,<=,!= or <>)
logical       :-- will check the condition is true or false

>>>and           :-- will must be true all condition
>>>or	         :-- will be true atleast one condition
>>>not           :--  true/false--- flase/true


membership   :-- will check the values is present or not in group 		of values
in           :-- will return true when element is present
not in       :-- will return true when element is not present


identify     :-- will compare the address 

is           :-- will true when the cell is null
is not       :-- will true when the cell contain data
